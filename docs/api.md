## `<ui>`

`<ui>`: components written once, drawn by native views on iOS and Android, by the DOM on the
web and in a webview on the desktop. Import this module; its parts are:

  style            Style, colors, Align and Justify, keys
  core/            the runtime: state, tree, reactivity, frames and commits, the wire format
  elements/        what apps build with: layout, text, input, media, lists, overlays,

```eskiu
               the platform, native modules and views, navigation, timers, display frames, gestures, animated values
```

  state/strings    owned strings (use_string)
  core/driver      what `ui agent` asks (UI_TEST builds only) and the clock it owns
  core/reload      the state a reload under `ui serve` keeps (UI_TEST builds only)
  apis/            the system: environment (platform, dark mode, accessibility, language),

```eskiu
               actions (keyboard, share, clipboard, haptics, announcements), storage, network
```

One UI thread; hosts deliver events and frames on it.

## `<ui/apis/network>`

The network through the platform: NSURLSession on iOS, HttpURLConnection on Android, the
browser's fetch on the web, so TLS, proxies and certificates are the system's.
Part of `<ui>` (src/ui.esk imports every part; they are not imported alone).

### FetchRequest

```eskiu
struct FetchRequest { string url; string method; string headers; string body; int timeout_ms; string save_to; }
```

A request: `headers` one "Name: value" per line; `method` "GET" when null; `body` sent
unless null; `timeout_ms` 0 for the platform's. With `save_to` (a file path; iOS and
Android) the body, bytes and all, goes to that file instead of the result: written whole
or not at all, and only for a 2xx status.

### FetchResult

```eskiu
struct FetchResult { int status; string body; string headers; string error; }
```

The answer, borrowed for the handler's call: the status (0 when the request failed, with
`error` saying why), the body as text and the response headers, one per line.

### PendingFetch

```eskiu
struct PendingFetch { int id; fn(FetchResult)->void on_done; }
```

A request waiting for its answer: its id and the handler (internal).

### ui_fetch

```eskiu
void ui_fetch(FetchRequest request, escaping fn(FetchResult)->void on_done)
```

Send `request`; on_done gets the result as an event, on the UI thread.

### ui_event_fetch

```eskiu
bool ui_event_fetch(int id, int status, string body, string headers)
```

The host's side: the request `id` finished (event 16; status 0: `body` is the error).

### ui_dispatch_fetch_event

```eskiu
bool ui_dispatch_fetch_event(*Event event)
```

Hands a fetch event (16) to the request waiting for it as a FetchResult and frees its
handler; false when no request has that id (internal).

### ui_cache_path

```eskiu
void ui_cache_path(string url, String* out)
```

Where ui_cached_file keeps `url`: the app's data directory, ui-cache/, a hash of the URL
and the URL's file name (its extension tells decoders the format).

### PendingCache

```eskiu
struct PendingCache { int fetch; String url; String path; List<fn(string)->void> waiting; }
```

A download for ui_cached_file: its request id, the URL, the cache path and every handler
waiting for it (internal).

### ui_cached_file

```eskiu
void ui_cached_file(string url, escaping fn(string)->void on_done)
```

`url`'s file in the app's cache: on_done gets its path, downloaded the first time and read
from the cache after that (when it is there already, on_done runs before this returns), or
null when the download failed or the app stopped first. The path is borrowed for the call.
iOS and Android: the web has no files (null).

### ui_answer_cache

```eskiu
void ui_answer_cache(*PendingCache pending, string path)
```

Each handler waiting for `pending` gets `path`, then it is freed.

### ui_free_pending_cache

```eskiu
void ui_free_pending_cache(*PendingCache pending)
```

Frees a PendingCache's strings and list (internal).

### CachedFile

```eskiu
struct CachedFile { String url; String path; int pending; bool unmounted; bool asking; *Signal<int> version; }
```

A use_cached_file's state: the URL, its path once there, and the downloads it waits for
(it is freed by the last of those, or by its block's unmount when none is left).

### ui_free_cached_file

```eskiu
void ui_free_cached_file(*CachedFile cached)
```

Frees a CachedFile (internal).

### use_cached_file

```eskiu
string use_cached_file(string url)
```

The path of `url` in the app's cache for this block: null until it is downloaded (the block
renders again then) or when it cannot be. The path is the block's until `url` changes.

Part of `<ui>` (src/ui.esk imports every part; they are not imported alone).

### ui_data_dir

The app's own data directory ("" on the web, which has none): the host reports it before

### ui_set_asset_host

The host's lookup for ui_asset_path, from hosts/bridge.esk.

### ui_store_find

The index of `key` among the loaded values, or -1 (internal).

### ui_storage_get


The value saved for `key`, or null. Borrowed until the next set or remove.

### ui_storage_set

## `<ui/core/boundary>`

Errors that do not close the app: ErrorBoundary, the rollback of a failed render, and the
reports of errors in renders, handlers and effects.
Part of `<ui>` (src/ui.esk imports every part; they are not imported alone).

### ErrorBoundary

```eskiu
void ErrorBoundary(escaping fn(UiError)->void fallback, escaping fn()->void content)
```

A boundary renders `content`. When it throws, the render's mutations are cut from the
commit, the nodes it made are freed without reaching the host, the boundary's previous
subtree is removed, and `fallback` renders in its place until ui_boundary_reset. A change
of an enclosing Scope's key makes a new boundary, which tries again. The root is a
boundary too, with a fallback the app may replace (ui_set_fallback).

  ErrorBoundary(void(UiError e) { Text("This part failed"); }) {

```eskiu
  Chart(data);
```

  }

### ui_take_boundary

```eskiu
void ui_take_boundary(*Node node)
```

The next element is an ErrorBoundary: it takes the staged content and fallback.

### ui_boundary_reset

```eskiu
void ui_boundary_reset(int id)
```

Try the boundary's content again (from a fallback's button, say). `id` is UiError.boundary;
a boundary that is gone or not showing its fallback is left alone.

### ui_set_fallback

```eskiu
void ui_set_fallback(escaping fn(UiError)->void fallback)
```

What the root shows when a render throws outside any ErrorBoundary.

### ui_on_error

```eskiu
void ui_on_error(escaping fn(UiError)->void handler)
```

Told every error the runtime catches (renders, handlers, effects). Without one they are
printed to stderr (the console on the web).

### ui_default_fallback

```eskiu
void ui_default_fallback(UiError error)
```

What an ErrorBoundary shows when it is given no fallback: "Something went wrong." and
the error's text.

### ui_where_name

```eskiu
string ui_where_name(int where)
```

Words for UiError.where: "a render", "a handler" or "an effect".

### ui_report_error

```eskiu
void ui_report_error(UiError error)
```

Hands an error to the ui_on_error handler (an exception it throws is ignored), or prints
it to stderr when there is none.

### ui_boundary_block

```eskiu
void ui_boundary_block()
```

The block of a boundary node (ui.builder while it runs).

### ui_render_failed

```eskiu
*Node ui_render_failed(*Node node, string text, int from, int writes, int journal, *Observer evaluating)
```

A render run by the frame (not inside a boundary's own block) threw: the nearest boundary
above `node` takes it, and is returned to run with its fallback. The root's fallback
failing is an error nothing can show, so it stops.

### ui_boundary_fail

```eskiu
void ui_boundary_fail(*Node node, string text, string path)
```

Marks the boundary `node` as failed with the error's text and scope path (copied; the
old ones are freed after the commit) and reports it (internal).

### ui_rollback

```eskiu
void ui_rollback(*Node node, int from, int writes, int journal, *Observer evaluating)
```

Undo what a failed render did since its save point, then empty the boundary: the commit is
cut back to `from`, the removals cut with it are sent again for the nodes the host knows,
and the boundary's children and hooks go (nodes made after the cut without a removal).

### ui_known

```eskiu
bool ui_known(*Node node)
```

Whether the host has heard (or will, with this commit) of the node. Outside a rollback
every node counts as known.

### ui_unwind_evaluating

```eskiu
void ui_unwind_evaluating(*Observer depth)
```

Observers a throw left evaluating (down to `depth`, the one computing when the work began)
are dirty again, to be computed when next read.

### ui_drop_staged

```eskiu
void ui_drop_staged()
```

What an element call staged for the next element, left behind by a throw.

### ui_boundary_clear

```eskiu
void ui_boundary_clear(*Node node)
```

Remove every child of the boundary and drop its hooks. A boundary whose block is running
keeps running: its matching state starts over, with no old children.

### ui_settle

```eskiu
void ui_settle(*Node node)
```

A node a throw left mid-run has its children in two lists (the old ones not matched yet,
and the ones this run emitted): gather them so ui_unmount reaches every one.

### ui_discard_slots

```eskiu
void ui_discard_slots(*Node node)
```

Drop a node's hooks as an unmount does (cleanups after the commit, then the state), and let
the next run make new ones.

### ui_free_boundary

```eskiu
void ui_free_boundary(*Boundary boundary)
```

Frees a Boundary's closures and strings (internal).

### ui_guard_cleanup

```eskiu
void ui_guard_cleanup(fn()->void callback)
```

Run an app's cleanup (an effect's, a use_mount's on_unmount), reporting a throw as an
effect's instead of stopping. The commit's own cleanups run unguarded: on the web a loop
inside a try is slow, and they are the runtime's.

## `<ui/core/diagnostics>`

Stopping with a message that says where: the scope path.
Part of `<ui>` (src/ui.esk imports every part; they are not imported alone).

### ui_kind_name

```eskiu
string ui_kind_name(int kind)
```

An element kind's name ("Column", "Text", ...), "Scope" for any other.

### ui_scope_path

```eskiu
void ui_scope_path(*String out)
```

Where the running block is, from the root down: `Column[0] > Row[key 3]`, each step
the component name or element kind with its key or its index among its siblings.

### ui_node_path

```eskiu
void ui_node_path(*Node node, *String out)
```

Appends the scope path of `node` to `out` (as ui_scope_path).

### ui_fail

```eskiu
void ui_fail(string message)
```

Prints `message` and the running block's scope path to stderr, then aborts.

### ui_fail_node

```eskiu
void ui_fail_node(string message, *Node node)
```

Prints `message` with `node`'s scope path (and, in a UI_SRCLOC build, where its element was
called from) to stderr, then aborts.

### ui_source_file

```eskiu
string ui_source_file(string file)
```

A position's file as shown: under the app's root, from there (internal).

### ui_source_at

```eskiu
void ui_source_at(*String out, UiSourceLoc at)
```

"\n  at FILE:LINE:COL" for a known position, appended to `out` (internal).

### ui_here

```eskiu
void ui_here(UiSourceLoc at)
```

For the element the running block makes next: `at` is its call (UI_HERE). The first one
given wins, so a component's position goes to the element it makes first.

### ui_fail_where

```eskiu
void ui_fail_where(string message, *Node node, UiSourceLoc at)
```

ui_fail_node with the position `at` (internal).

### ui_require

```eskiu
void ui_require(bool ok, string message)
```

ui_fail(message) unless `ok`.

### ui_require_consistent

```eskiu
void ui_require_consistent()
```

A throw out of a block, handler or effect is caught by the runtime (src/core/boundary.esk).
One that still escapes is an internal error: a caller that catches it leaves the runtime
mid-phase, and the next entry point stops here instead of running on it.


## `<ui/core/driver>`

The driver: what `ui agent` asks a dev or test build (UI_TEST) and the clock it owns.
Part of `<ui>` (src/ui.esk imports it only when UI_TEST is defined, which the ui tool does
for `ui serve` builds; a release build has none of it).

A request is one JSON object with an "op" (docs/agents.md lists them). ui_driver_request
answers it with one JSON object, from the core where it can (tree, state, logs, perf,
the clock, back). An op only the host can do (layout, input, its animations, its memory)
is answered with a directive for the host instead, {"host": OP, ...}; the host does it
and hands its result to ui_driver_finish, which answers the request.

The virtual clock: once a request takes it ({"op": "hello", "clock": "virtual"}), the
core's timers and use_frame ticks no longer go to the host's clock. They run on the
driver's time, which moves only when a "clock" request advances it, so nothing moves
between two requests.

### Memo


```eskiu

```

### on_cleanup


Inside a use_effect callback: `callback` runs before the effect's next run and when its

## `<ui/core/reload>`

Reload that keeps state: under `ui serve` (UI_TEST builds only) the host asks the running
core for a snapshot before it stops it for a new build, and hands it to the new core before
starting it. The new core gives it back as the app mounts: the router's routes, and each
signal whose identity and type did not change.
Part of `<ui>` (src/ui.esk imports it only when UI_TEST is defined).

The snapshot is text, one record per line, fields split by tabs (a tab, a newline or a
backslash in a field is written \t, \n or \\):

  ui-reload 1
  route    /places/2                         one per route, root first
  signal   Column[0] > TodoRow[key 3]  0  int  5
  keyed    filter  text  done

A `signal` record is a scope's Nth signal (use_signal or use_string, counted in the order
the scope declares them), found by the scope's path as `ui agent state` prints it; a
`keyed` one is a use_signal_keyed signal, found by its key wherever it is. The type is
spelled: int, int64, int16, uint8, char, uint, uint64, bool, double, float, or text for a
use_string. A signal of another type (a pointer, a struct, a closure, a borrowed string)
is not saved: it starts from its initial value.

## `<ui/core/runtime>`

The runtime: its state, frames and commits, events from the host.
Part of `<ui>` (src/ui.esk imports every part; they are not imported alone).

### Event

```eskiu
struct Event {
    int extra2; int extra3; }
}
```

Event kinds: 1 press, 2 change (text), 3 focus (value 1 focused, 0 blurred), 4 toggle
(value 1 on, 0 off), 5 scroll (value the offset, extra the viewport height), 6 alert
answered (the id is the request, value the button's index, -1 dismissed), 7 refresh
(the user pulled a scroll's RefreshControl), 8 native module event (name the channel, text
the payload; no node), 9 native view event (name and text from the view), 10 route (the
browser went to `text`, at history index `value`; no node), 11 layout (the node's frame:
value x, extra y, width and height, relative to its parent), 12 timer (the id is the
timer's token), 13 hover (value 1 when a pointer enters the node, 0 when it leaves),
14 value (a Slider moved to `value`), 15 answer (the text a request asked for: the id is
the request), 16 fetch (a request finished: value the status, text the body or the error,
name the headers), 17 pan (value the phase, extra dx, width dy, height the x velocity,
extra2 the y velocity), 18 display frame (no node; the time in seconds in `value`, the microseconds in `extra`), 19 the app
went to the foreground (value 1) or the background (value 0; no node), 20 long press. A layout's window
position is in extra2 and extra3.

### Insets

What the host reports about the screen, in points: the system bars and display cutouts
on each side, and the software keyboard over the bottom.

### Window

```eskiu

```

The window's size in points, and its scale in percent (200 on a 2x screen).

### Ui

```eskiu

    *Node builder;
    *Observer tracking;
    List<*Node> by_id;

    List<int> retired_ids;
```

Element props: Style, colors, Align and Justify, keys.
Part of `<ui>` (src/ui.esk imports every part; they are not imported alone).


### key

```eskiu

```

A key from a number (an item's id).

### Style

```eskiu
struct Style {
    Key key; int gap = 8; int padding = 0; string label;
    int width; int height; int grow; bool wrap;
    int64 background = -1; int64 color = -1; int font_size; int font_weight;
    int border_width; int64 border_color = -1; int radius; int opacity = 100;
    int align; int justify;
    bool absolute; int left = kUnset; int top = kUnset; int right = kUnset; int bottom = kUnset;
    double aspect_ratio;
    int translate_x; int translate_y; int scale = 100; int rotate;
    int transition_ms; int easing;
    int min_width; int max_width; int min_height; int max_height;
    int shadow;
    bool cover;
    bool pixelated;
    int64 gradient = -1; int gradient_angle = 180;
    string font;
    int blur;
    string test_id;
}
```

`label` is the accessible name (ARIA label, accessibilityLabel, contentDescription).
width and height are points (0: sized by content and parent); grow shares the free
space along the parent's direction (flex-grow); wrap lets a row's children flow onto
more lines (flex-wrap). The visual props: colors from rgb()/rgba() (-1: the platform's
default), font_size in points and font_weight 100 to 900 (0: default), border_width and
radius in points, opacity in percent, align (children across the axis) and justify
(children along it) from the Align and Justify members (0: default).
`absolute` takes the element out of its parent's flow: left, top, right and bottom
(points, kUnset: not set) place it against the parent's edges, and the other children are
laid out as if it were not there. `aspect_ratio` (width over height, 0: none) gives the
side that is not set from the one that is.
translate_x and translate_y (points), scale (percent) and rotate (degrees) move the drawn
element without changing its layout; transition_ms (0: none) and easing (the Easing
members) animate changes of opacity, the transforms and the colors on the host.
min_width, max_width, min_height and max_height bound the size the layout gives (points;
0: no bound). `shadow` raises the element over what is under it: a soft shadow below it,
its elevation in points (0: none), as React Native's elevation. `cover` makes an Image fill
its box, cropped, instead of fitting in it (React Native's resizeMode "cover"). `pixelated`
scales an Image without smoothing, each pixel a sharp square (pixel art; CSS's
image-rendering: pixelated). `gradient` paints the background as a linear gradient from
`background` (transparent when unset) to this color (RGBA), along `gradient_angle` degrees
as CSS measures it: 180 (the default) top to bottom, 90 left to right, 135 corner to corner.
`blur` (points, 0: none) shows what is behind the element blurred, as frosted glass, under
its background and children (iOS's materials, CSS backdrop-filter; Android, which cannot
blur behind a view, paints a translucent material instead).
`font` draws the text in a font file from the app's assets ("fonts/VT323.ttf"; TrueType or
OpenType), one file per weight, so font_weight does not apply to it.
`test_id` names the element for tests and the driver (`ui agent web tap add`): it is not the
accessibility label and never reaches the screen or a screen reader; a release build ignores
it.
